정합성 개선 필요
1
기반자료를 '관리'하는 화면이 없음
예시 화면 3개가 권한·감사·모니터링뿐이라, 정작 관리 대상인 데이터(데이터셋·데이터맵)를 어떻게 다루는지 안 보입니다.
이렇게 고치기
데이터셋·데이터맵을 관리하는 화면 1개를 예시에 추가하고, 데이터를 등록 → 승인 → 갱신 → 폐기하는 흐름을 그림으로. 지금 권한 화면은 나 장표와 겹치니 줄여도 됩니다.
근거 · 이 요구사항은 “분석모델·데이터셋·통계·데이터맵을 관리하는 기능”을 요구합니다.
2
관리자가 분석환경을 배정·회수하는 기능이 없음
분석가의 'GPU 신청'만 있고, 관리자가 승인·배정·회수하는 쪽이 없습니다. 이 사업은 GPU 배분이 배점과 직결됩니다.
이렇게 고치기
분석가 신청 → 관리자 승인·배정 → 다 쓰면 회수하는 흐름과, GPU를 얼마나 나눠줬는지 보는 화면을 관리자 기능에 추가하세요.
근거 · 이 요구사항은 “분석환경을 구성·할당·회수하는 기능”을 요구합니다.
